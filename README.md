# 비 더 베이스볼 레전드

18세 한국인 신인 타자 또는 투수로 시작하는 야구 선수 커리어 시뮬레이션입니다. KBO 신인 지명을 거쳐 시즌을 진행하며, 30세부터 은퇴를 선택하거나 40세에 자동 은퇴합니다. 타자는 결정적 한 타석의 결과를 시즌 기록에 합산하고, 투수는 선발·불펜 역할에 따라 투구 이닝과 평균자책점 등을 기록합니다.

홈에서 집중(1시즌), 일반(2시즌), 고속(3시즌) 모드를 고른 뒤 타자 또는 투수를 선택합니다. 타자는 프로필에서 타석 방향을 설정한 뒤 야구장 위에서 수비 포지션을 고릅니다. 투수는 프로필에서 선발·불펜을 선택하면 바로 커리어를 시작합니다. 구단을 고르면 기록을 한 시즌씩 공개하고, 선수 능력은 시즌마다 자동으로 성장하거나 하락합니다. 결정적 타석과 다른 리그의 영입 제안이 생기면 진행을 멈추고 선택을 받습니다. 모드가 없던 이전 저장은 집중 모드로 이어지며, 기존 선수 유형은 수비형에서 포수, 컨택형에서 내야수, 장타형에서 외야수로 이어집니다.

## 실행

```powershell
npm ci
npm run dev
npm run build
npm run build:toss
```

`dev`와 `build`는 일반 브라우저 저장소를 사용합니다. `build:toss`는 앱인토스 게임 사용자 식별 키와 SDK 저장소를 사용하며 `be-the-baseball-legend.ait`를 생성합니다. `be-the-baseball-legend`는 가칭 앱 식별자입니다. 실제 콘솔에 등록된 식별자와 다르면 `apps-in-toss.config.ts`를 수정해 다시 빌드하세요. 브라우저와 앱인토스 저장은 기기별로 관리됩니다.

## 해외 진출

타자 기준

| 대상 | 완료 시즌 | OVR | 최근 시즌 타석 | 최근 시즌 OPS |
| --- | ---: | ---: | ---: | ---: |
| NPB | 3 | 58 | 220 | .690 |
| MLB | 6 | 73 | 300 | .790 |

투수는 선발·불펜별 투구 이닝과 평균자책점 기준을 적용합니다. 자세한 조건은 게임의 진출 가능 리그에서 확인할 수 있습니다. 조건은 게임 규칙입니다. MLB 제안은 KBO에서 직접 받거나 NPB를 거쳐 받을 수 있습니다. 상위 구단일수록 우승 가능성이 커지지만 같은 선수에게 주어지는 출전 기회가 줄 수 있습니다.
